# Pawn Shop Research Prototype
This is my research prototype for the CSCE 490/492 research milestone.

This project's purpose was to research how the Godot engine worked, in order to more accurately understand how to build our pawn shop game. In this demo, I was able to work through and understand the systems in Godot that will directly relate to how our game will operate.

# Controls
Move: WASD
Interact: E
Button Press: Mouse click
